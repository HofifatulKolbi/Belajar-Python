# ANALISIS KODE PROGRAM
## build_embeddings.py
Kode tersebut berfungsi untuk membangun dataset embedding FaceNet dari folder data/train, kemudian menyimpannya menjadi dua file: X_train.npy untuk embedding dan y_train.npy untuk label kelas. Prosesnya dimulai dengan fungsi iter_images() yang membaca seluruh folder dalam data/train sebagai kelas, lalu menghasilkan path gambar beserta nama kelasnya. Selanjutnya, fungsi build_matrix() melakukan iterasi pada setiap gambar, memanggil embed_from_path() untuk mengekstrak embedding wajah menggunakan FaceNet. Jika wajah tidak terdeteksi, file gambar dimasukkan ke list bad; sebaliknya, embedding disimpan ke list X dan label kelasnya ke list y. Setelah semua gambar selesai diproses, embedding dan label diubah menjadi array NumPy dan disimpan ke disk. Secara keseluruhan, script ini berguna untuk menyiapkan dataset numerik yang akan digunakan untuk melatih model klasifikasi wajah, sekaligus memberikan laporan berapa banyak gambar yang gagal terdeteksi wajahnya.
## eval_folder.py
Kode tersebut bertujuan mengevaluasi akurasi model FaceNet-SVM pada folder data/val dengan cara membaca setiap gambar validasi berdasarkan nama kelasnya, mengekstraksi embedding menggunakan embed_from_path(), lalu memprediksi identitas wajah menggunakan model SVM yang telah dimuat dari facenet_svm.joblib. Untuk setiap gambar yang berhasil terdeteksi wajahnya, script mencatat label asli dan label prediksi, memperbarui statistik jumlah benar dan total per kelas, kemudian menghitung akurasi keseluruhan dengan membandingkan seluruh pasangan label asli dan prediksi. Pada akhir proses, kode menampilkan akurasi total serta ringkasan performa per kelas dalam format “jumlah prediksi benar / total gambar,” sehingga pengguna dapat melihat seberapa baik model mengenali setiap identitas pada data validasi.
## predict_one.py
Kode tersebut digunakan untuk melakukan prediksi identitas wajah pada satu gambar menggunakan model SVM yang telah dilatih dan disimpan dalam file facenet_svm.joblib. Fungsi predict_image() pertama-tama mengekstraksi embedding dari gambar menggunakan embed_from_path(), lalu menjalankan predict_proba() untuk memperoleh probabilitas setiap kelas. Kelas dengan probabilitas tertinggi diambil sebagai prediksi, dan jika nilai confidence tersebut berada di bawah ambang batas (threshold) 0.55, gambar dianggap tidak sesuai dengan identitas mana pun dan dikembalikan sebagai "UNKNOWN"; sedangkan jika tidak ada wajah terdeteksi, fungsi mengembalikan "NO_FACE". Saat script dijalankan langsung, ia akan memprediksi gambar val/a1.jpg dan menampilkan hasil label serta tingkat kepercayaannya.
## train_classifier.py
Kode tersebut digunakan untuk melatih model klasifikasi wajah berbasis SVM menggunakan embedding FaceNet yang sebelumnya disimpan dalam file X_train.npy dan y_train.npy. Pertama, pipeline dibangun dengan dua komponen: StandardScaler untuk menormalkan data agar setiap fitur memiliki skala yang seimbang, dan SVC dengan kernel RBF yang sering dipakai pada data berdimensi tinggi seperti embedding wajah. Untuk mencegah error ketika jumlah data sedikit, nilai cross-validation ditentukan dengan cv = min(2, len(X)), sehingga evaluasi model tetap berjalan meskipun dataset sangat kecil. Setelah cross-validation menghitung akurasi rata-rata, model SVM kemudian dilatih menggunakan seluruh data dan hasilnya disimpan ke dalam file facenet_svm.joblib agar dapat digunakan untuk prediksi di skrip lain.
## train_knn.py
Kode tersebut digunakan untuk melatih model klasifikasi wajah menggunakan algoritma K-Nearest Neighbors (KNN) berdasarkan embedding FaceNet yang telah disimpan dalam file X_train.npy dan y_train.npy. Model dibangun menggunakan pipeline yang terdiri dari dua langkah: StandardScaler untuk menormalkan fitur-fitur embedding agar semua dimensi memiliki skala yang seimbang, dan KNeighborsClassifier dengan n_neighbors=3 serta jarak Euclidean sebagai metrik kedekatan. Setelah pipeline selesai dibuat, model dilatih dengan seluruh data embedding tanpa cross-validation, karena KNN umumnya bekerja baik langsung pada dataset kecil maupun besar. Model yang sudah dilatih kemudian disimpan dalam file facenet_knn.joblib, sehingga dapat digunakan untuk proses identifikasi wajah pada skrip prediksi lain tanpa perlu melatih ulang model.
## utils_facenet.py
Kode tersebut membangun modul utilitas FaceNet yang terdiri dari fungsi-fungsi utama untuk membaca gambar, melakukan deteksi dan alignment wajah menggunakan MTCNN, kemudian menghasilkan embedding 512-dimensi dengan model InceptionResnetV1 yang telah dilatih pada dataset VGGFace2. Proses dimulai dengan menentukan perangkat komputasi (CPU atau CUDA), memuat MTCNN untuk mendeteksi wajah dan melakukan cropping berukuran 160×160 piksel, lalu menyiapkan model embedder untuk ekstraksi fitur. Fungsi read_img_bgr() membaca gambar dalam format BGR milik OpenCV, sementara bgr_to_pil() mengubahnya menjadi PIL Image agar kompatibel dengan MTCNN. Fungsi face_align() menjalankan deteksi wajah dan mengembalikan tensor hasil alignment, kemudian embed_face_tensor() mengubah tensor tersebut menjadi embedding numerik. Fungsi embed_from_path() mengintegrasikan seluruh proses dari membaca gambar hingga menghasilkan embedding lengkap, dan akhirnya cosine_similarity() digunakan untuk mengukur tingkat kemiripan antara dua embedding wajah. Dengan modul ini, seluruh operasi deteksi dan representasi wajah dapat dilakukan secara konsisten dan efisien.
## verify_cli.py
Kode tersebut berfungsi sebagai program command-line sederhana untuk memverifikasi apakah dua gambar wajah merupakan orang yang sama menggunakan embedding FaceNet. Program menerima dua path gambar melalui argumen terminal (img1 dan img2), lalu memanggil fungsi embed_from_path() untuk mengekstraksi embedding masing-masing wajah. Jika salah satu gambar tidak berhasil dideteksi wajahnya, program menampilkan pesan “Wajah tidak terdeteksi.” Jika kedua embedding tersedia, program menghitung kemiripan keduanya menggunakan cosine similarity melalui fungsi cosine_similarity(). Hasil kemiripan tersebut kemudian dibandingkan dengan ambang batas (--th, default 0.85) untuk menentukan apakah kedua wajah dianggap cocok (“MATCH”) atau tidak (“NO MATCH”), dan seluruh informasi dicetak ke layar. Program ini praktis untuk uji cepat verifikasi wajah dua gambar.
## verify_pair.py
Kode tersebut digunakan untuk membandingkan dua gambar wajah dan menentukan apakah keduanya berasal dari orang yang sama menggunakan FaceNet dan metrik cosine similarity. Proses dimulai dengan mengambil embedding dari masing-masing gambar menggunakan fungsi embed_from_path(), yang secara otomatis mendeteksi wajah, melakukan alignment, dan menghasilkan representasi numerik 512 dimensi. Jika salah satu gambar gagal terdeteksi wajahnya, program langsung memberikan pesan “Wajah tidak terdeteksi.” Namun jika kedua embedding tersedia, keduanya dibandingkan menggunakan cosine_similarity(), dan nilai kemiripannya dicetak. Berdasarkan ambang batas 0.85, program kemudian memutuskan apakah kedua wajah dianggap cocok (MATCH) atau tidak (NO MATCH). Kode ini merupakan contoh sederhana verifikasi wajah 1:1 menggunakan FaceNet.
